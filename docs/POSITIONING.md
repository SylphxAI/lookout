# Positioning — Lookout

**One-liner:** Web answers with source-level proof.

- **User:** an agent that needs a public-web hit, or a page it can cite.
- **Job:** rank hits from public adapters, then fetch and extract the page you mean to cite.
- **Promise:** the result keeps the URL, the span, the warnings, and the gaps. Search and fetch do not require an API key.
- **Identity:** package `@sylphx/lookout`, bin `lookout`, MCP `io.github.SylphxAI/lookout`, site <https://sylphxai.github.io/lookout/>.
- **Not the headline:** `web_research` is an explicit multi-step tool. It is not what `web_search` does.
- **Companion tools:** Citra, Iris, Cue, Spine, Locus, and Lookout are independent products. Each one is installed on its own.

See [vision.md](./vision.md) and [capabilities.md](./capabilities.md) for the destination and the owned capabilities. [TOOL_SURFACE.md](./TOOL_SURFACE.md) is the tool policy and [EVIDENCE_CONTRACT.md](./EVIDENCE_CONTRACT.md) is the result contract.
